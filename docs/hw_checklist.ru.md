# Проверка на железе

[English version](hw_checklist.md)

Что проверить на плате, прежде чем рискованное изменение попадёт в master: переписывание (`docs/rewrite_plan.md`), обновление библиотеки, работа с картами или USB. Не каждому PR нужно всё: проходите разделы, которых может коснуться изменение, и всегда раздел **Smoke**.

Поставьте `debug=1` в `karabas.ini` и держите терминал на USB-порту платы: большинство пунктов подтверждается логом. Отмечайте плату в каждом прогоне: **G** Karabas Go, **M** Mini, **MG** Mini G. Пункты только для одной платы помечены.

## Smoke

- [ ] Плата загружается в BOOT-ядро, виден список ядер (браузер FT812 или текстовый OSD).
- [ ] В логе: `USB host: N hardware spinlocks free`, нет `PIO programs did not load`, нет `Last boot hung / panicked / halted`.
- [ ] `DIAG` каждые 10 с: у core1 ненулевое число циклов, `usb sof 1000/s` с максимальным промежутком около 1000 мкс, `disc` / `own` / `ovf` равны 0, ни у одной задачи не кончается стек.
- [ ] USB-клавиатура за хабом работает в браузере; ядро загружается и возвращается в BOOT (Ctrl+Alt+Backspace).

## Ядра

- [ ] BOOT-ядро: список ядер, длинные имена, выбор сохраняется после перезагрузки.
- [ ] Ядро с OSD (tsconf): загружается, его ROM доходят (`ROM ... ms` с режимом связи в логе), Win+Esc открывает и закрывает OSD.
- [ ] Ядро FILELOADER (NES): список файлов, игра загружается, последний файл запоминается (id записывается в файл ядра).
- [ ] Ядро с burst (`FPGA caps` с burst в логе) и классическое (старое ядро, ответа на caps нет).
- [ ] Ядро со своим `spi_freq`.
- [ ] Самое тяжёлое ядро (nanomig): загружается, Kickstart подгружается сам (пункт `FL` с `autoload`), работает.
- [ ] Автозапуск (`[autoload]`): обратный отсчёт, клавиша его останавливает.
- [ ] Ctrl+Alt+Backspace (джойстик Start+X) перезагружает в BOOT, в том числе из OSD.

## OSD

- [ ] Переключатели сразу меняют ядро, сохраняются в файл ядра и возвращаются после перезагрузки ядра.
- [ ] Горячие клавиши пунктов OSD (Ctrl+Alt+Del у tsconf).
- [ ] Древовидное меню (nanomig): Enter / Right открывают страницу `►`, Esc возвращает назад, курсор запоминается для каждой страницы, путь в строке заголовка; пункт с `show_if` появляется, а пункт с `enable_if` становится серым вместе со своим переключателем; горячая клавиша пункта с другой страницы открывает эту страницу. Плоское меню (tsconf) выглядит как раньше.
- [ ] Длинные списки: скроллбар в последней колонке браузера ядер и файлового браузера (слот на страницу), меню ядра и списка Wi-Fi (ползунок не больше половины дорожки); нет ни скроллбара, ни пустой колонки, если список помещается; меню ядра прокручивается за курсором.
- [ ] Браузеры `F` / `FL` показывают каталоги (голубые, с `/` в конце) и только файлы с расширениями пункта («Files: ...» в строке подсказки).
- [ ] Слоты `F`: подключение, извлечение, браузер открывается в каталоге последнего образа (диск 2 после диска 1), Esc — в каталог самого слота.
- [ ] Монтирование образов читает и пишет (образ диска, записанный ядром, сохраняет данные после перезагрузки).
- [ ] `.sav` (NES с `CAPS_BK`): создаётся в `saves/`, сохраняется после другой игры, другого ядра, горячей клавиши перезагрузки.
- [ ] Загрузчик ioctl `FL`: файл отправлен, CRC-32 в логе совпадает с файлом на ПК.
- [ ] **G:** физический дисковод: `[ Physical DF0 ]` / `DF1` в слоте `F` с `physical`, ядро читает дисковод.

## Карты памяти

- [ ] SD-карта FAT32 и exFAT: списки, длинные имена, открытие по id.
- [ ] Нет `karabas.ini`: значения по умолчанию, первое сохранение из Settings создаёт файл. Неверная строка (> 79 символов): `karabas.ini is invalid`, значения по умолчанию.
- [ ] Settings сохраняют только изменённые ключи (`karabas.new`, затем переименование), комментарии остаются.
- [ ] MSC (действие кнопки `msc` или `AT+KARABAS=msc`): экран msc, карта на ПК, скорость чтения / записи, извлечение перезагружает плату (eject в Linux, «Безопасное извлечение» в Windows).
- [ ] MSC со второй картой (`msc2`, BTN2 удержать 2 с в BOOT): «SD Card 2» на ПК, извлечение; без карты экран сообщает об этом, перезагрузка через 5 с.
- [ ] `AT+KARABAS=sd2test` (BOOT-ядро): чтение на 4..24 МГц, на 24 МГц может не пройти.
- [ ] Нет ошибок ввода-вывода в `journalctl -k` во время MSC.

## Ввод

- [ ] USB-клавиатура и мышь, напрямую и за хабом; мышь в меню FT.
- [ ] Low-speed устройство за хабом (дешёвый геймпад, старая клавиатура): `own` остаётся 0.
- [ ] HID-геймпады: с `drivers/*.ini` и без него (автоматическая раскладка); два порта джойстиков держат свои геймпады.
- [ ] Setup > Map USB gamepad: обучение, сохранение ini, Forget.
- [ ] XInput-геймпад (8BitDo M30).
- [ ] PS/2-клавиатура.
- [ ] **G:** джойстики Sega.
- [ ] Кнопки на плате: действия `core.btn` (нажатие и удержание), `bootsel`, `msc`, `msc2`.
- [ ] Клавиши не теряются под нагрузкой (загрузка ядра, перерисовка браузера FT, включённый лог).

## Принтер

- [ ] USB-принтер (Epson LX-300): страница из ядра печатается целиком, без повторов и пропусков строк (bulk OUT).

## Время и сеть (BOOT-ядро)

- [ ] RTC: Setup RTC устанавливает дату и время, они сохраняются после выключения питания.
- [ ] RTC ядер: MC146818A (profi на Go / Mini, pcxt: время в DOS) в BCD при стёртом EEPROM (регистр B 02h), DS1307 (next), ZX Evolution (tsconf, profi на Mini G), MSM6242B (nanomig: часы Workbench).
- [ ] Часовой пояс `tz`: текстовый Setup и страница Clock на FT, сохраняется.
- [ ] Синхронизация NTP устанавливает RTC.
- [ ] Wi-Fi: статус, поиск, пароль, подключение; управление потоком CTS (`AT+UART_DEF`).
- [ ] Wi-Fi: Upgrade module (`AT+CIUPDATE`) и Reset module (`AT+RESTORE`) с индикатором прогресса.

## Последовательный мост

- [ ] Байты хоста доходят до UART ядра и обратно.
- [ ] `AT+KARABAS=list`, `version`, `boot` (BOOTSEL), `msc`, `msc2`, `esp` / `uart` (BOOT-ядро: консоль AT модуля ESP и обратно).

## Дисплеи

- [ ] **MG:** браузер FT812: видеорежимы (попробовать, подтвердить, откатить), страницы настроек (System, Clock, Wi-Fi, Gamepad), звуки и щелчок клавиш, цвета.
- [ ] **MG:** картинка FT812 появляется при каждой загрузке (нет чёрного экрана, см. `FT start` в логе).
- [ ] Текстовый браузер OSD при `[ft812] enabled=0`.
- [ ] Светодиодная матрица: `core` (бегущая строка BOOT, индикаторы ядра), `scroll`, `effect` (clock, drive со слотами образов), `image`, `blank`; яркость `[matrix]` и вид часов / индикаторов; значок в BOOTSEL и MSC; индикатор загрузки ядра.
- [ ] OLED.

## Диагностика

- [ ] В заголовке текстового OSD по очереди (3 с) показываются сборка FPGA и сборка прошивки; `AT+KARABAS=version`.
- [ ] `debug=0`: лога нет, ничего не замедлилось. `debug=1`: лог загрузки хранится, пока терминал не откроет порт.
- [ ] Поток в CDC (тяжёлый лог) при наборе на клавиатуре: нет зависания, порт не сбрасывается.
- [ ] Watchdog: зависание перезагружает плату, следующая загрузка пишет в лог `Last boot hung: ...`.

## Базовые замеры

Сняты на master до переписывания, для сравнения: 2026-10-27, master 3d1d797 (Pico-PIO-USB 0.7.3), Mini G, `debug=1`, те же SD-карты.

| Что | Как | Значение |
|---|---|---|
| Размер прошивки | `arm-none-eabi-size` для elf Mini G | 618296 text, 12032 data, 140840 bss (3d1d797) |
| Загрузка до BOOT-ядра | от отключения USB при перезагрузке до `Core type: Boot` в логе | ~1,6 с (после извлечения в MSC) |
| Битстрим BOOT-ядра | `Elapsed time` в логе | 504..506 мс (693096 байт) |
| Загрузка nanomig | битстрим + ROM + Kickstart | битстрим 619 мс (746600 байт); Kickstart 512 КБ за 1117 мс (burst); ядро работает через ~2,6 с после выбора. Загрузка с HDF на 14 ГБ: ~700 чтений секторов за 10 с, самое долгое ожидание 4,9 мс |
| Загрузчик файлов | игра NES, мс и КБ/с в логе | битстрим NES 605 мс; игра 256 КБ за 1093 мс (burst); `.sav` подключён |
| Чтение / запись SD1 в MSC | `dd` с `iflag=direct` / `oflag=direct`, exFAT 32 ГБ | чтение 469 кБ/с (64 МБ), запись 399 кБ/с (32 МБ) |
| Чтение SD2 в MSC | то же с `msc2`, смонтировано только для чтения (на вторую карту не пишем) | чтение 375 кБ/с (25 МБ) |
| `DIAG` | циклы на ядро, максимальные промежутки, куча, самые маленькие стеки, SOF | BOOT-ядро, браузер FT в простое: core0 ~2200 циклов/с, максимальный промежуток 10..15 мс; core1 ~85000, максимальный промежуток ~440 мкс; свободная куча 50080; свободный стек APP 3523, USB 1745, USBD 942, INPUT 817, MATRIX 902, OLED 928 слов; SOF 1000/с, максимальный промежуток ~1015 мкс, самый длинный кадр ~210 мкс (low-speed геймпад за хабом) |
| Сбросы USB-порта устройства хостом | `reset full-speed USB device` в `journalctl -k` | были и до переписывания с `debug=1`: от нескольких до 200+ в час, один раз и во время загрузки nanomig с HDF |
