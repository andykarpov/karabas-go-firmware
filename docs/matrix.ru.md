# LED-матрица

[English version](matrix.md)

LED-матрица — необязательная дополнительная плата с двумя двухцветными матрицами 8x8. Она подключена по шине I2C к RP2040 и доступна через порты 0x70, 0x71.

Что реализовано:

- рисование индикаторов уровня громкости по аудиоданным со стороны FPGA;
- рисование отдельных пикселей со стороны ZX Spectrum;
- настройки для каждого ядра (ключ `"matrix"` в `core.json`, см. ниже): бегущая строка, эффекты, картинки и анимации.

## Режимы ядра

Что показывает матрица, задаёт ключ `"matrix"` в `core.json` ядра (`make_core` в `karabas-go-tools`, 256 байт со смещения 768 в файле ядра, `FILE_POS_MATRIX`):

- `core` (по умолчанию, и для ядер, собранных раньше): ядро само рисует на матрице или показывает свои аудиоиндикаторы, как описано ниже. Загрузочное ядро прокручивает `KARABAS GO`.
- `scroll`: текст до 64 символов с подстановками `{name}`, `{build}`, `{time}`, `{date}`; цвета `yellow`, `red`, `green`, `rainbow` (по символам), `gradient` (по столбцам); `step_ms`, `repeat`.
- `effect`: `clock` (ЧЧ:ММ, секунды бегут по нижней строке), `fire`, `life` (игра «Жизнь» Конвея), `scanner`, `rain`, `plasma`, `stars`, `pong`, `drive` (подключённые образы дисков: при обращении загорается точка, зелёная при чтении и красная при записи, а положение головки над образом показано жёлтым, до 4 образов; нет образа: пунктирная линия).
- `image`: картинка 16x8 или анимация до 4 кадров.
- `blank`: выключено.

После `repeat` проходов строки (или циклов анимации) матрица переходит в `then`: `core`, `effect` или `blank`.

```json
"matrix": {"mode": "scroll", "text": "NES {build}", "color": "rainbow", "repeat": 2, "then": "core"}
```

`karabas.ini`, секция `[matrix]`: `enabled=0` оставляет матрицу тёмной во всех ядрах, `brightness=1..16` задаёт яркость для всех ядер (`0`: как задаёт ядро). Оба ключа есть в Setup > Settings загрузочного меню.

Вид эффекта часов и аудиоиндикаторов ядер тоже задаётся в `[matrix]`, для всех ядер (Setup > Settings > Matrix effects, в графическом меню: System > Matrix effects; пока правятся параметры, матрица показывает редактируемый плагин):

| Ключ | Значения | По умолчанию |
|---|---|---|
| `clock_hours`, `clock_minutes` | `green`, `yellow`, `red` | `green`, `yellow` |
| `clock_seconds` | `dot` (бежит по нижней строке), `colon` (мигает между ЧЧ и ММ), `bar` (растёт по нижней строке за минуту), `off` | `dot` |
| `clock_seconds_color` | `green`, `yellow`, `red` | `red` |
| `meter_style` | `bars` (две строки на канал), `wide` (четыре строки), `center` (левый канал влево от середины, правый вправо), `mono` (более громкий канал на всех строках), `vertical` (два столбца, растущие вверх) | `bars` |
| `meter_colors` | `zones` (зелёный, жёлтый, вверху красный), `green`, `yellow`, `red`, `fire` (жёлтый с красной вершиной) | `zones` |
| `meter_decay` | `slow`, `normal`, `fast` | `normal` |
| `meter_peak` | `1`: точка удерживает пик секунду, потом падает | `0` |

Ядро может рисовать на матрице (регистры ниже, `CMD_MATRIX_*`) только в режиме `core`; в остальных режимах его записи игнорируются.

## Поддержка в ZX Spectrum

Со стороны ZX Spectrum (пока реализована для ядер TS-Conf и ZX Spectrum Next) матрица доступна через управляющий и информационный порты ZX UNO #FC3B (64571) / #FD3B (64827) и их свободные регистры F0, F1, F2.

В режиме `core` LED-матрица стартует с индикатора уровня громкости.
При первой записи данных в управляющий или информационный регистр матрица переключится в режим произвольного рисования.

### Управляющий регистр 0xF0

Запись в этот регистр выполняет действие, описанное ниже.

Биты управляющего регистра:
- бит 0: значение 1 очищает матрицу
- бит 1: значение 1 обновляет матрицу из виртуального кадрового буфера
- бит 2: значение 1 устанавливает уровень яркости из битов 7-4
- бит 3: значение 1 переключает матрицу в режим индикатора уровня громкости, значение 0 переключает в режим произвольного рисования
- биты 7-4: задают яркость матрицы, когда бит 2 = 1

### Регистр координат пикселя 0xF1

Запись в этот регистр задаёт следующую позицию X-Y на матрице, в которой будет нарисован пиксель.
Младшие биты 3-0 задают позицию X (от 0 до 15).
Старшие биты 7-4 задают позицию Y (от 0 до 7).

### Регистр данных пикселя 0xF2

Запись в этот регистр задаёт в виртуальном кадровом буфере цвет пикселя в позиции X-Y (из регистра 0xF1): 0 выключен, 1 красный, 2 жёлтый, 3 зелёный.
Чтобы показать пиксель или набор пикселей, выполните действие «обновить» в управляющем регистре 0xF0.

## Пример программы для компилятора Boriel ZX Basic

Этот код заполняет матрицу случайными пикселями и обновляет её в цикле.

```
' ********************************************************************
' Dot Matrix demo on Karabas mini Go by Andy Karpov (2026-07-05)
' ********************************************************************

CLS: BORDER 0: PAPER 0: INK 7: CLS

CONST COLOR_NONE as uByte = 0
CONST COLOR_RED as uByte = 1
CONST COLOR_YELLOW as uByte = 2
CONST COLOR_GREEN as uByte = 3

CONST PORT_CTL as uLong = 64571
CONST PORT_DATA as uLong = 64827

CONST REG_CTL as uByte = 240
CONST REG_XY as uByte = 241
CONST REG_PIX as uByte = 242

CONST CTL_CLEAR as uByte = 1
CONST CTL_UPDATE as uByte = 2
CONST CTL_BRIGHTNESS as uByte = 4

SUB matrix_clear()
    OUT PORT_CTL, REG_CTL
    OUT PORT_DATA, CTL_CLEAR
END SUB

SUB matrix_update()
    OUT PORT_CTL, REG_CTL
    OUT PORT_DATA, CTL_UPDATE
END SUB

SUB matrix_draw_pixel(y as uByte, x as uByte, c as uByte)
    OUT PORT_CTL, REG_XY
    OUT PORT_DATA, x + y*16
    OUT PORT_CTL, REG_PIX
    OUT PORT_DATA, c
END SUB

SUB main()
    matrix_clear()
    DO
        DIM x, y, c AS uByte
        FOR y = 0 TO 7
        FOR x = 0 to 15
            LET c = INT(4 * RND)
            matrix_draw_pixel(y, x, c)
        NEXT x
        NEXT y 
        matrix_update()
    LOOP
END SUB

' -----------------------------------------------------------------------------------

main()

' Debug stop
PAUSE 0
```
