# USB-контроллеры XInput

[English version](xinput.md)

Прошивка использует [Ryzee119/tusb_xinput](https://github.com/Ryzee119/tusb_xinput),
скопированный в `third_party/tusb_xinput` (вместе с лицензией), как дополнительный драйвер класса USB-хоста TinyUSB.
В копии сохранён API `bool open()`, который есть у драйверов классов TinyUSB 0.18 (pico-sdk 2.2.0);
новый API `uint16_t open()` из upstream рассчитан на более поздний TinyUSB.
Наше единственное изменение (помечено `karabas`): перед подключением проводного пада Xbox 360
драйвер читает его строковые дескрипторы и шлёт vendor-запрос 0x01 (как Windows и Linux xpad).
Многие сторонние пады (8BitDo, Hori, ...) без этого не шлют ввод, а TinyUSB 0.18
при перечислении строки не читает.
Целевое устройство: **8BitDo M30 2.4G, подключённый USB-кабелем для данных**.
Bluetooth и приёмник 2.4G у M30 в этой интеграции не реализованы.
Сам контроллер должен определяться в режиме XInput; устройство в режиме HID по-прежнему
работает через существующий механизм HID-драйверов.

Отчёты XInput попадают в существующее состояние джойстика Sega, команды FPGA и горячие клавиши
OSD. Геймпады XInput и настроенные USB HID-джойстики делят два USB-порта
(`src/input/usb_joy`): геймпад при подключении занимает первый свободный порт,
сначала левый, и держит его до отключения. Третий геймпад не
передаётся, пока не освободится порт. Состояния джойстиков на плате объединяются
как раньше. Отключение геймпада сбрасывает его кнопки, не перемещая другой геймпад
на другой порт.

| Элемент XInput | Элемент Karabas |
| --- | --- |
| D-pad / левый стик (мёртвая зона 50%) | Up, Down, Left, Right |
| A, B, X, Y | A, B, X, Y |
| RB или RT (>30) | C |
| LB или LT (>30) | Z |
| Start | Start |
| Back / Select | Mode |

Для C/Z принимаются и плечевые кнопки, и курки, чтобы учесть
варианты раскладки M30. Это раскладка по умолчанию, а не утверждение, проверенное на железе,
для каждой ревизии M30. Кнопки Guide и нажатие на стик игнорируются.

## Проверка на железе

1. Прошейте плату и подключите M30 к USB-порту хоста платы
   кабелем для данных. Для проводного режима следуйте [руководству M30 2.4G](https://download.8bitdo.com/Manual/Controller/M30-2.4g/M30_2.4g.pdf)
   (инструкция X+Start для модели с Bluetooth не подходит).
2. Включите `debug=1` в `karabas.ini`. Найдите в логе `XInput mounted` с VID/PID
   и `type=3` (проводной Xbox 360).
3. Проверьте направления, диагонали, A/B/C/X/Y/Z, Start и Mode в ядре и в OSD.
   Лог `XInput` печатает слово кнопок и значения курков, чтобы диагностировать раскладку.
4. Удерживая кнопку, выдерните кабель: кнопка должна отпуститься. Подключите снова и
   проверьте ещё раз. Также проверьте вместе с USB-клавиатурой/мышью и, если есть,
   с настроенным HID-джойстиком.

Беспроводные приёмники Xbox и другие семейства контроллеров Xbox выходят за рамки
проверяемой цели, хотя драйвер из upstream их распознаёт.

Целевая сборка: `ninja -C build karabas_minig`. Тесты порта:
`ctest --test-dir build-test -R test_usb_joy_slots`.
