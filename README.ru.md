# Прошивка Karabas Go

[![Build](https://github.com/andykarpov/karabas-go-firmware/actions/workflows/build.yml/badge.svg?branch=master)](https://github.com/andykarpov/karabas-go-firmware/actions/workflows/build.yml)

[English](README.md) | Русский

Прошивка микроконтроллера RP2040 (Raspberry Pi Pico) для ретрокомпьютеров на ПЛИС семейства
Karabas Go. Микроконтроллер работает в паре с ПЛИС: загружает ядра (битстримы) с SD-карты,
рисует экранные меню, обслуживает клавиатуры, мыши, джойстики и часы реального времени и
обменивается данными с запущенным ядром по SPI.

**[Маппер USB-геймпадов](https://andykarpov.github.io/karabas-go-firmware/hidmapper/)**: настройка
USB HID геймпада в браузере и загрузка его ini-драйвера для папки `/drivers/` на SD-карте.
Большинство геймпадов работает и без драйвера, см. [USB HID геймпады](docs/usb_gamepads.ru.md).

## Платы

| Плата | Файлы ядер | Файл прошивки в релизе |
| --- | --- | --- |
| Karabas Go | `*.kg1` | `karabas-go-firmware.uf2` |
| Karabas Mini | `*.kg2` | `karabas-mini-firmware.uf2` |
| Karabas Mini G | `*.kg3` | `karabas-minig-firmware.uf2` |

## Возможности

- **Загрузка ядер.** Браузер ядер показывает ядра с SD-карты. Если на плате есть видеочип FT812,
  меню графическое, иначе текстовое. Выбранное ядро может запускаться автоматически по
  таймауту. Битстрим уходит в ПЛИС через PIO и DMA, за ним загружаются ПЗУ ядра.
- **OSD.** Ядра с экранным меню берут из файла ядра свои пункты, переключатели и горячие клавиши.
  Длинное меню прокручивается; ядро может разбить его на подменю (страницы, в том числе
  вложенные), разделители и пункты, которые видны или доступны только при определённом значении
  другого пункта (ключи `core.json` описаны в
  [make_core](https://github.com/andykarpov/karabas-go-tools/blob/master/make_core/README.ru.md#подменю-страницы-и-условные-пункты)).
  Образы дисков монтируются с SD-карты и остаются открытыми, пока работает ядро, с чтением и
  записью. Поддерживаются и загрузчики файлов; у ядра-загрузчика с пунктами меню они открываются
  из списка файлов по Tab или O (Options), Esc возвращает к файлам. На Karabas Go вместо образа можно выбрать
  физический дисковод.
- **Ввод.**
  - USB-клавиатуры (в том числе NKRO) и мыши.
  - USB HID геймпады: раскладка строится по их HID-дескриптору, либо задаётся ini-драйвером из
    [маппера](https://andykarpov.github.io/karabas-go-firmware/hidmapper/) или из OSD.
  - XInput-геймпады (проводной протокол Xbox 360, например 8BitDo M30 2.4G).
  - PS/2-клавиатуры.
  - Сега-джойстики в разъёмах платы (Karabas Go).
  - Любой джойстик приходит в ядро как 6-кнопочный геймпад Sega Mega Drive.
- **USB host.** Работает на втором ядре RP2040 через PIO-USB, хабы поддерживаются. Драйвер
  USB-принтера (Epson LX-300+II) в работе.
- **Часы реального времени.** Настраиваются в меню Setup и передаются в ядро.
- **Настройка Wi-Fi** модуля ESP8266 в меню Setup (браузер ядер): поиск сетей, пароль,
  подключение. Модуль запоминает сеть и подключается к ней при старте; у него включается
  управление потоком CTS.
- **SD-карта как USB-накопитель.** Компьютер видит SD-карту как USB-флешку, вынимать её из платы
  не нужно.
- **USB-serial мост.** USB-serial порт платы соединён с UART ядра, а несколько команд
  `AT+KARABAS=` управляют самой прошивкой. USB-UART переходник, вставленный в USB host, забирает
  UART ядра себе.
- **Дополнительная периферия**, определяется при старте: FT812, OLED-дисплей, LED-матрица,
  I2C-расширитель (Go), ESP8266, MIDI (Mini G).
- **Быстрая передача.** Ядра, которые это поддерживают, получают ПЗУ и файлы пакетами до 512 байт
  по второму chip select.

## Где взять прошивку

Каждая сборка `master`, которая меняет прошивку, становится
[релизом](https://github.com/andykarpov/karabas-go-firmware/releases) с тремя `.uf2` файлами.
Эти же файлы попадают в папки `firmware/` репозиториев
[karabas-go](https://github.com/andykarpov/karabas-go) и
[karabas-mini](https://github.com/andykarpov/karabas-mini).

### Тестовая прошивка из pull request

CI собирает прошивку для каждого PR. Скачать её может любой, кто вошёл в GitHub, права на
репозиторий не нужны.

1. Откройте страницу PR и перейдите на вкладку **Checks**.
2. Выберите слева **Build**, затем **Summary** в самом верху левой колонки.
3. Внизу страницы, в блоке **Artifacts**, скачайте архив для своей платы:

   | Плата | Артефакт |
   |---|---|
   | Karabas Go | `firmware-go` |
   | Karabas Mini | `firmware-mini` |
   | Karabas Mini G | `firmware-minig` |

4. Распакуйте zip и прошейте `firmware.uf2`, как описано в разделе
   [Обновление прошивки](#обновление-прошивки).

На **Checks** показан прогон последнего коммита PR, это самая свежая сборка. Это тестовая
прошивка, не релиз: чтобы вернуться на стабильную, прошейте `.uf2` из
[Releases](https://github.com/andykarpov/karabas-go-firmware/releases). GitHub хранит
артефакты 90 дней.

## Обновление прошивки

1. Переведите RP2040 в режим BOOTSEL: зажмите кнопку **Boot**, нажмите и отпустите **Reset**,
   затем отпустите **Boot**. Другой способ: отправьте `AT+KARABAS=boot` в USB-serial порт платы.
2. Появится USB-накопитель `RPI-RP2`. Скопируйте на него `.uf2` файл для своей платы.
3. Плата перезапустится с новой прошивкой.

## SD-карта

| Путь | Что это |
| --- | --- |
| `/boot.kg1` (`.kg2`, `.kg3`) | браузер ядер, загружается при включении |
| `/*.kg1` (`.kg2`, `.kg3`) | ядра платы |
| `/karabas.ini` | настройки, см. ниже |
| `/drivers/*.ini` | драйверы USB-геймпадов, необязательно ([формат](docs/usb_gamepads.ru.md#ini-драйвер)) |

Файловая система: FAT16, FAT32 или exFAT. Ядра собираются утилитой
[make_core](https://github.com/andykarpov/karabas-go-tools/tree/master/make_core) из
[karabas-go-tools](https://github.com/andykarpov/karabas-go-tools).

### karabas.ini

Файл необязателен: без него прошивка берёт значения по умолчанию из таблицы ниже. Все ключи
меняются в меню: Setup > Settings текстового браузера ядер (`[setup]`, `[autoload]`, `[matrix]`,
`enabled` / `video_mode` из `[ft812]`) и графический setup (все). Сохранение создаёт файл или
записывает только изменённые ключи, остальной файл остаётся как был. Строки не длиннее 79
символов, иначе файл целиком игнорируется.

| Секция | Ключ | По умолчанию | Значение |
| --- | --- | --- | --- |
| `[setup]` | `debug` | `0` | `1`: отладочный лог в USB-serial порт |
| | `dvi_only` | `0` | `1`: ядра отключают HDMI-фреймы (звук, инфокадры) и выдают чистый DVI |
| | `tz` | `+00:00` | смещение от UTC для NTP sync, задаётся в Setup RTC / на странице Clock, например `+03:00`, `-04:30`; без летнего времени |
| `[ft812]` | `enabled` | `1` | `1`: графический браузер ядер на FT812 |
| | `video_mode` | `1` | видеорежим FT812: `0` 640x480@60, `1` 800x600@60 |
| | `sound`, `click` | `1`, `1` | звуки меню |
| | `time`, `date`, `char` | `1`, `1`, `1` | показывать в графическом браузере часы, дату и картинку «Карабаса» |
| | `color_bg`, `color_gradient`, `color_button`, `color_active`, `color_text`, `color_text_active`, `color_copyright` | `010101`, `0000c8`, `202026`, `0000c8`, `ffffff`, `ffffff`, `787878` | цвета (hex RGB) |
| | `3d_buttons` | `0` | `1`: кнопки с тенью и светлым краем (кроме 800x600: там это слишком тяжело для FT812) |
| | `mouse_speed` | `3` | скорость указателя мыши в графическом меню, 1..5 |
| `[matrix]` | `enabled`, `brightness`, `clock_*`, `meter_*` | `1`, `0`, ... | LED-матрица, см. [docs/matrix.ru.md](docs/matrix.ru.md) |
| `[autoload]` | `enabled`, `timeout`, `core` | `0`, `15`, нет | запуск ядра `core` через `timeout` секунд |

Пример:

```ini
[setup]
debug=0
tz=+03:00

[ft812]
video_mode=0

[autoload]
enabled=1
timeout=5
core=tsconf
```

## Управление

| Клавиши | Джойстик | Действие |
| --- | --- | --- |
| Menu (Win) + Esc | Start + C, Start + Select | открыть / закрыть OSD запущенного ядра |
| Ctrl + Alt + Backspace | Start + X | перезапустить микроконтроллер и вернуться в браузер ядер |
| стрелки, Enter, Esc | крестовина, A / B, C или Select | навигация по меню (удержание направления — автоповтор); кроме самого маппинга геймпада |
| Left | Left | назад, где у Left нет другой роли: меню Setup, About, статус и список сетей Wi-Fi, вкладки графического Setup; на первом ядре графического браузера — на кнопку Setup (Enter открывает, Right возвращает) |
| цифры | Up / Down | цифра под курсором в поле даты / времени |
| ввод текста | Up / Down, Right, Left | текстовое поле Wi-Fi: сменить последний символ, добавить, удалить |
| `S` | Start (браузер ядер) | Setup: часы, Wi-Fi и Settings (браузер ядер), маппер USB-геймпадов; в графическом браузере — графический Setup (настройки, видеорежим, темы) |
| `A` (OSD ядра) | | About |
| Enter, Right (OSD ядра) | A / B, Right | открыть подменю пункта `►` |
| Esc (OSD ядра) | C или Select | из подменю в меню уровнем выше |
| Delete / Backspace (OSD ядра) | | извлечь образ диска выбранного привода |
| Space (графический браузер) | | переключиться на текстовый браузер |
| мышь (графический браузер, Setup) | | наведение, клик, колесо; правая кнопка = Esc |
| `G` (текстовый браузер) | | переключиться на графический браузер, даже если он выключен в `karabas.ini` |

Ядра могут задавать свои горячие клавиши OSD.

## Кнопки на плате

Что делают кнопки **BTN1** и **BTN2**, задаёт каждое ядро (`buttons` в его `core.json`, см.
`make_core` в karabas-go-tools): передать в ядро (reset, NMI... как решит ядро; по умолчанию),
открыть OSD, вернуться в меню, перезагрузить ядро, перезагрузиться в BOOTSEL или в USB mass
storage — по нажатию или по удержанию. В загрузочном меню BTN1 перезагружает в BOOTSEL, BTN2 — в
USB mass storage (удержание 2 с — со второй SD-картой).

## SD-карта как USB-накопитель

Нажмите **BTN2** в загрузочном меню или отправьте `AT+KARABAS=msc` в serial порт. Плата покажет
компьютеру свою SD-карту как USB-накопитель, остальное в это время не работает, об этом сообщает
экран. Чтобы вернуться в обычный режим, извлеките накопитель на компьютере.

Так же работает и вторая SD-карта (слот FPGA, ей пользуются ядра): удерживайте **BTN2** в
загрузочном меню 2 секунды или отправьте `AT+KARABAS=msc2`. Накопитель называется «SD Card 2» и
работает медленнее (около 300 КБ/с). Если в слоте нет карты, плата вернётся в меню.

## USB-serial мост

Байты с компьютера уходят в UART запущенного ядра. На строки, начинающиеся с `AT+KARABAS=`,
отвечает сама прошивка:

| Команда | Действие |
| --- | --- |
| `AT+KARABAS=list` | список ядер на SD-карте с их сборками |
| `AT+KARABAS=version` | `+KARABAS:<прошивка>;<плата>;<id ядра>;<сборка ядра>`: сборка прошивки, плата (1 Go, 2 Mini, 3 Mini G) и запущенное ядро |
| `AT+KARABAS=boot` | перезапуск в режим BOOTSEL для обновления прошивки |
| `AT+KARABAS=msc` | перезапуск с SD-картой как USB-накопителем |
| `AT+KARABAS=msc2` | перезапуск со второй SD-картой (слот FPGA) как USB-накопителем |
| `AT+KARABAS=sd2test` | только в браузере ядер: чтение второй SD-карты на нескольких частотах SPI (проверка карты и линка) |
| `AT+KARABAS=esp` | только в браузере ядер: мост переключается на ESP8266, для его AT-команд (CR, LF или CR LF из терминала уходят как CR LF) |
| `AT+KARABAS=uart` | обратно на UART ядра |
| `AT+KARABAS=key:<клавиши>` | нажать и отпустить клавиши, как USB-клавиатура (ядро, OSD, горячие клавиши): клавиши через пробел, каждая из модификаторов и одной клавиши через `+` (`ctrl+alt+del`, `menu+esc`, `menu+f3`, `enter`, `f12`, `0x29` код HID), 100 мс нажата, 40 мс отпущена |
| `AT+KARABAS=type:<текст>` | набрать текст (печатный ASCII, раскладка US) |
| `AT+KARABAS=hold:<клавиша>` / `release` | держать клавишу (до `release` или следующей клавиши) / отпустить все |

### USB-UART переходник

USB-UART переходник (CDC ACM, FTDI, CP210x или CH34x), вставленный в USB host платы, пока он
вставлен, забирает UART ядра: байты ядра уходят в переходник, а байты из него в ядро. Переходник
работает в 8N1 на скорости ядра: 115200 или скорость, которую задаёт ядро (делитель DLL / DLM в
ZX Evo RS232). Используется только первый переходник. USB-serial порт платы остаётся для
отладочного лога и команд `AT+KARABAS=`, остальные байты в него в это время отбрасываются.

## Сборка из исходников

Прошивка написана на C11 на pico-sdk с FreeRTOS SMP и TinyUSB, собирается CMake и тулчейном
arm-none-eabi от earlephilhower ([pico-quick-toolchain](https://github.com/earlephilhower/pico-quick-toolchain)
4.1.0: нужен его newlib). Версии pico-sdk и FreeRTOS зафиксированы в `CMakeLists.txt` и
скачиваются сами, если `PICO_SDK_PATH` / `FREERTOS_KERNEL_PATH` не заданы.

```sh
cmake -S . -B build -G Ninja                  # -DPICO_TOOLCHAIN_PATH=..., если тулчейна нет в PATH
ninja -C build                                # все платы
ninja -C build karabas_minig                  # одна плата: karabas_go, karabas_mini, karabas_minig
cmake -S test -B build-test -G Ninja && ninja -C build-test && ctest --test-dir build-test   # юнит-тесты
```

Результат: `build/karabas_<плата>.uf2`, его копируют на диск `RPI-RP2` платы в режиме BOOTSEL
(туда переводит `AT+KARABAS=boot` по USB). CI ([build.yml](.github/workflows/build.yml))
собирает все платы, запускает тесты и выпускает релизы. Маппер геймпадов лежит в
[`tools/hidmapper`](tools/hidmapper) и публикуется в GitHub Pages через
[hidmapper.yml](.github/workflows/hidmapper.yml).

Архитектура описана в [CLAUDE.md](CLAUDE.md) (на английском): задачи и блокировки, модули,
формат файла ядра и соглашения по коду.
